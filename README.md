# 言語文化　夏目漱石「夢十夜」

東京書籍『新編言語文化』所収「夢十夜」（第一夜・第六夜）に第八夜を加えた単元の教材です。GitHub Pages で公開して、生徒の iPad から使います。

- `index.html` … 入口ページ
- `soseki.html` … 導入「夏目漱石の生涯　視聴ワーク」
  - 動画：大人の国語便覧「夏目漱石の生涯」（https://www.youtube.com/watch?v=j3_XzxMAGTE）
  - ① 見ながら：章ごとの聞き取り問題（全37問）と、心の状態（−5〜+5）・理由
  - ② 見た後に：人生グラフ、「夢十夜」の時期、夢の予想
  - ③ 提出：まとめをコピーしてロイロノートのテキストカードに貼る
  - 答えは端末のブラウザにだけ保存されます（外部への送信はありません）

- `daiichiya.html` … 第一夜「百年、待ってみる」（本文を読む前にプレイ）
  - 話の骨組みだけを見せ、手がかり（白い頬、真珠貝、星の破片、百合の匂い、接吻など）は本文に残す
  - 「」の言葉は教科書の表記どおり、それ以外の語りはゲーム用に書いたもの
  - 最後に予想（Q1 なぜ「百年はもう来ていた」と気づいたか／Q2 百合は何か）を書き、ロイロ用にコピーできる

- `daihachiya.html` … 第八夜「床屋の鏡の前で」（本文を読む前にプレイ）
  - 発問の軸：なぜこの夢は金魚売で終わるのか。床屋の中の「自分」（鏡の枠の中を人が横切るのを、座ったまま、頭を押さえられて見ている）と、金魚売（桶の枠の中を金魚が泳ぐのを、頬杖をついて動かずに見ている）が同じ形になっていることに気づかせる
  - 鏡（縦長の楕円）と桶（横長の楕円）は同じ木の枠。最後は桶をのぞきこむ画面で、水に映る影は鏡の中の自分と同じ形、金魚は窓の外の人と同じく横切っていく。説明は入れない
  - 古い写真のようなセピアの画面。人物には顔と着物の色をつけ、水に映る影だけは影のまま
  - 細かいところ（庄太郎の名前とパナマ帽、豆腐屋の頬、芸者、帳場の女の姿と十円札、金魚の種類）は本文に残す
  - 第八夜は教科書に載っていないので、「」の言葉は青空文庫の本文を教科書の第一夜に合わせた表記（言う・座る・目 など）にしている
  - 最後に予想を書き、ロイロ用にコピーできる。問いはプリント③の②・④の①と同じ「床屋の中の『自分』は、どんな人だと思う？」（Ａ 見たいものを、最後まで見ようとがんばる人／Ｂ 周りに動かされて、思いどおりにできない人／Ｃ その他）

問題文や選択肢は `soseki.html` の `CHAPTERS` を書きかえると変更できます。
